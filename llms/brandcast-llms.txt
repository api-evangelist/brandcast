# Brandcast

> Brandcast is a no-code digital customer experience and website platform that fuses web design, content creation, and brand asset management into a single system, letting business and marketing teams build and update branded websites, proposals, and content programmatically. The Brandcast API opens the Design Studio to developers to create websites from templates and update site content. Brandcast's website product has since been rebranded as "Sites" and joined Vev.

## API

- [Brandcast API — Developer Portal](https://developer.brandcast.io/): Overview of the Brandcast API for programmatic Design Studio actions (create websites from templates, update website content). Base URL https://api.brandcast-prod.io. Authentication is an API key in the x-api-key header, issued by Brandcast and sent over HTTPS.
- [Brandcast API — Docs mirror](https://api.brandcast.io/): Mirror of the developer documentation.

## Company

- [Brandcast / Sites](https://www.brandcast.com): Company site (now redirects to the Sites product at sites.design following the Vev acquisition).
- [Brandcast on GitHub](https://github.com/brandcast): Brandcast engineering GitHub organization (open-source npm packages and internal tooling; no dedicated API client SDK published).
